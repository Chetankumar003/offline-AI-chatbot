# 🤖 Offline AI Chatbot Project

A lightweight, privacy-focused AI Chatbot built in Python using **Streamlit** and **Hugging Face Transformers**. 

## ✨ Features
- **100% Pure Python:** No external API keys or paid subscriptions required.
- **Offline Capable:** Automatically caches the LLM locally inside the project folder after the first run.
- **Context Memory:** Remembers previous messages in the conversation.
- **Export Chats:** Allows users to download their conversation history as a `.txt` file.
